# FC26 Manager Career Game

An interactive web-based game featuring a home screen inspired by FC26, with a dynamic menu system and hover-based content updates.

## Features

✨ **Interactive Menu System**
- Left sidebar navigation with multiple game modes
- Hover effects that update the main content area
- Smooth transitions and animations
- Active menu item tracking

🎮 **Game Modes**
- Manager Career
- Pro Clubs
- Ultimate Team
- Player Career
- Clubs
- Kick Off
- Learn to Play

🎨 **Design Features**
- FC26-inspired dark theme with cyan accents
- Responsive layout
- Smooth hover animations
- Dynamic background color changes per mode
- Glowing effects and modern UI elements

## How to Use

1. Open `index.html` in your web browser
2. Hover over menu items in the left sidebar
3. Watch the main content area update with:
   - New title
   - New description
   - New subtitle
   - Different background color
   - Updated play button
4. Click the play button to expand a game mode
5. Click a menu item to set it as active

## Files

- `index.html` - Main HTML structure
- `style.css` - All styling and animations
- `script.js` - Interactivity and menu functionality

## Customization

You can easily customize:
- Menu items and their data in `menuData` object in `script.js`
- Colors and styling in `style.css`
- Background gradients per mode
- Button text and functionality
